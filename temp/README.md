# Temporary Reference Materials

本目录保存 Repository Re-initialization 期间仍可能有用的旧项目材料。

- `product/`：旧需求、产品想法、人格/对话/记忆契约。
- `engineering/`：旧 architecture spine、ADR、工程研究、代码导览和技术上下文。

这些文件是 reference，不是 authority。重新采用的结论必须写入 `docs/product/` 或 `docs/architecture/`，并经过当前项目判断。产品与架构重初始化完成且不再依赖这些材料后，删除整个 `temp/`；Git 历史仍可用于追溯。
