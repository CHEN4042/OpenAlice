# Memory Contract

本文件承载 CAP-5。首版只要求**可靠持久化 + 最小召回**，具体算法不在首版固化。这里的“记忆模块”是逻辑边界（包 + 明确接口），不预设物理拆分。

## Required behavior

1. 对话内容必须可靠持久化：写入成功即长期可读，服务重启不丢，且每条记录可追溯到真实发生过的消息。
2. 对话层可以向独立的记忆边界请求召回，而不是只依赖当前会话窗口。
3. 记忆模块返回的内容必须可追溯到真实发生过的消息或明确记录的用户事实。
4. 回复生成只能使用可信召回；召回为空、降级或冲突未解决时，不得声称记得、不得补写历史。

## P1 acceptance

以下两条**任一成立**即算首版通过，不要求同时满足：

- 重启后能引用重启前刚聊过的具体细节；
- 能按当前话题找回较早（非本会话窗口内）的会话内容。

## Deferred algorithm

以下内容需要后续论文、实验和真实会话样本决定，不进入首版产品承诺：

- 记忆的抽取单位、表示形式与写入时机；
- 检索、重排、时间与作用域策略；
- 记忆分层（长期/短期）、话题重要度、衰减、遗忘与容忍度相关机制；
- 偏好推断如何与记忆模块协作；
- **记忆内部**的纠错、忘记、冲突与重建策略（回答阶段的“搜索 × 记忆冲突披露”不属于此列，仍属首版契约）；
- 评估指标、中文验收集和记忆质量门禁。
